Generated by `NCP-WISDM-Baselines.ipynb`. Watch accelerometer + gyroscope, 30 features, 10 s windows.
Train: 31 users / 9321 windows. Validation: 10 users / 3060 windows
(every validation user has all 18 classes; 170 validation windows per class).
Test users (10) were **not** scored.

Selected **lr=0.05, epoch 39** (highest validation Macro F1; ties -> earlier epoch).
At that epoch training Macro F1 is 0.758 vs validation 0.719
(gap 0.040). Training and validation scores are close, so the MLP is **underfitting** (limited by the features and/or the training budget) rather than memorising the training people.

The best epoch for lr=0.01, 0.03 is within 5 epochs of the 50-epoch cap: validation Macro F1 was still rising, so more epochs would probably help. The budget is fixed by the protocol, so we report this rather than extend it.
Curves: `mlp_loss_curves.png`; full history: `mlp_history.csv`.

Logistic regression: 171 / 1000 iterations, convergence warnings: 0.
Training Macro F1 0.658 vs validation 0.662.
